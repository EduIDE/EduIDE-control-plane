# Decisions

Decisions of the grilling session of 2026-11-18 (G) and implementation decisions of the same day (U).
Each row links the ADRs that implement it.

## Grilling decisions

| Nr. | Question | Decision | ADR |
|---|---|---|---|
| G1 | Load targets | Provisional: 1,000 concurrent sessions per deployment, 200 launches per minute in a burst, control plane below 150 MiB per deployment. Phase 0 measures production. | [0013](0013-observability.md), [0015](0015-test-strategy.md) |
| G2 | URL scheme | Path based on one instance host per deployment, as today. No subdomain per session. | [0004](0004-gateway-api-only.md), [0005](0005-session-auth-at-gateway.md) |
| G3 | Webviews and mini browser | Fixed host `webview.<instance host>` instead of `<uuid>.webview.<host>`. No wildcard in DNS, certificate and routes. The workbench stays on a separate origin from the webviews. Phase 0 spike covers Markdown preview, extension webviews, HTML preview and service workers. The images set `THEIA_WEBVIEW_EXTERNAL_ENDPOINT` and `THEIA_MINI_BROWSER_HOST_PATTERN`. | [0004](0004-gateway-api-only.md), [0005](0005-session-auth-at-gateway.md) |
| G4 | Second line of defence in front of the IDE | The IDE stays on `127.0.0.1`. The agent is a loopback proxy including WebSockets and forwards only requests with a valid `X-EduIDE-Instance-Token`. The HTTPRoute sets the header with a `RequestHeaderModifier`, overwriting client values. The Secret is created at prewarm time, the claim does not change it. NetworkPolicy stays mandatory. Residual risk: the token is in the HTTPRoute spec. | [0006](0006-agent-sidecar.md), [0009](0009-claim-protocol.md), [0019](0019-network-isolation.md) |
| G5 | Location of the authz service | Own binary `authz` with own image and Deployment (2 replicas, PDB, informer for sessions only). Separate failure area and release from the service. | [0002](0002-go-single-module-four-binaries.md), [0005](0005-session-auth-at-gateway.md), [0014](0014-operator-service-per-deployment.md) |
| G6 | API group | `eduide.github.io` for CRDs (for example `idesessions.eduide.github.io`, version `v1alpha1`) and prefix for labels and annotations. Scaler annotations are aligned. | [0003](0003-own-crd-group.md), [0017](0017-migration-parallel-run.md) |
| G7 | Extensions in the IDE | One extension `eduide-session` replaces the data bridge and the monitor. It opens no server and only calls the agent on localhost (long-poll for data and warnings, heartbeat on real input). The agent adds the connection state (no browser after the claim counts as idle). The commands `dataBridge.getEnv` and `dataBridge.getEnvState` stay unchanged. The old extensions run out after the migration. | [0006](0006-agent-sidecar.md), [0016](0016-activity-detection.md) |
| G8 | Capacity pressure | The operator evicts: when a session pod is stuck on capacity (`Unschedulable` or quota), it deletes the oldest idle pod of any pool and holds all pools at 0 idle while the pressure lasts. After 45 s without room the session gets `capacity-exhausted` (instead of 555). Pressure shows in metrics and `IDEPool` status, the pool scaler only plans. No PriorityClass. | [0008](0008-idepool-scale-bare-pods.md), [0009](0009-claim-protocol.md) |
| G9 | Sentry | No Sentry in the control plane, only OTel (Prometheus, Jaeger v2, logs with `trace_id`). Browser Sentry of the landing page stays optional, and the landing page also sends `traceparent`. Sentry could later be an OTLP target. | [0013](0013-observability.md) |
| G10 | Chart and CRDs | Two charts in this repo: `eduide-control-plane-crds` (per cluster) and `eduide-control-plane` (per deployment), published as OCI. EduIDE-Helm includes them. Rules for version skew: CRD chart first and additive only, operators tolerate unknown fields (server-side apply with own field manager), fields are removed only when no deployment uses them (CI schema diff), the operator checks the minimum CRD version at start. | [0011](0011-crd-versioning-cel.md), [0014](0014-operator-service-per-deployment.md), [0018](0018-charts-oci.md) |
| G11 | Repo name | `EduIDE-control-plane`. Module `github.com/EduIDE/EduIDE-control-plane`, images `ghcr.io/eduide/eduide-control-plane/{operator,service,authz,agent}`. EduIDE-Cloud is archived after the migration. | [0002](0002-go-single-module-four-binaries.md), [0018](0018-charts-oci.md) |
| G12 | Schedule | As soon as possible, steered by the exit criteria of the phases, not by the calendar. Order: test deployments, pilot, production. No move of a productive deployment during exam periods. The way back to the Java stack stays open per deployment until the end of the following month. The Java stack gets only security fixes and the immediate measures. | [0017](0017-migration-parallel-run.md) |
| G13 | Who builds | Claude builds everything and uses subagents, in work packages against fixed contracts. Sonnet implements, Opus reviews. Changes in real clusters and creating the GitHub repo only with approval. | [0001](0001-adr-madr.md), [0015](0015-test-strategy.md) |
| G14 | Launch and lifecycle | Launch is idempotent (key: template plus workspace, without persistence template plus hash of the start data). `sessionsPerUser` per deployment, default 3, then `session-limit-reached` with the list of running sessions. Timeouts per template (idle 60 min, warning after 50 min, max 24 h). Stopping always discards the pod, `volume` workspaces stay. The landing page shows an overview per user. | [0007](0007-persistence-modes.md), [0009](0009-claim-protocol.md), [0010](0010-rest-api-spec-first.md), [0016](0016-activity-detection.md) |
| G15 | Overview in the landing page | Title from `gitUri` (last path part without user prefix) or the optional Artemis parameter `title`. Subtitle is the template with logo and last used. Status running or not running. Actions: open and end for running, start and delete (with confirmation) for not running, sessions without workspace only open and end. Non-secret display data as `display.title` and `display.source`. Templates with `listed: false` get no start tile but keep name and logo in the overview. Endpoint `GET /api/v1/me/overview` with live updates over SSE. | [0010](0010-rest-api-spec-first.md) |
| G16 | Artemis token | The token travels only in the URL fragment (`#artemisToken=...`). The landing page reads it first, stores it in `sessionStorage`, removes the fragment with `history.replaceState`, then starts Keycloak, and deletes the entry after the launch. `?artemisToken` is still read during the migration and logged as deprecated. `gitUri` and `appDef` stay query parameters. A required e2e covers a launch from Artemis without an existing login. | [0010](0010-rest-api-spec-first.md), [0012](0012-user-data-secrets-allowlist.md) |
| G17 | Jaeger | One Jaeger v2 per cluster, not public, retention 7 days. Spans hold no e-mail addresses or names, only a pseudonymous user id (hash with a salt per deployment) and the session id. The OTLP endpoint is configurable per deployment. | [0013](0013-observability.md) |
| G18 | Data into the session | Allowlist `injectableKeys` per template with a rule per key (`https` and allowed hosts for `ARTEMIS_URL` and `GIT_URI`, `GIT_USER` and `GIT_MAIL` from the token, limits for `ARTEMIS_TOKEN`, build systems for `TEMPLATE`, `THEIA` as static env). No `fromSecrets`, no `fromConfigMaps`, unknown keys give 400. At most 8 KiB per launch. The Secret is owned by the session, the agent keeps data in memory only. Never in logs, traces, metrics or status, an e2e test greps for the token. | [0006](0006-agent-sidecar.md), [0012](0012-user-data-secrets-allowlist.md), [0015](0015-test-strategy.md) |
| G19 | Deleting workspaces | After last use (`status.lastUsed`, set at start and end of every session), never while a session runs. `retention` per deployment (default 14 days), overridable per template. Warning in the overview three days before expiry, "start" extends. Two stages: `Expired`, then after 24 h deletion of PVC and CR, cancel with an annotation. Import sets `lastUsed` to the import time. | [0007](0007-persistence-modes.md), [0017](0017-migration-parallel-run.md) |

## Implementation decisions

| Nr. | Topic | Decision | ADR |
|---|---|---|---|
| U1 | Go | Go 1.27.4. | [0002](0002-go-single-module-four-binaries.md) |
| U2 | Monorepo | Holds the control plane (operator, service, authz, agent), the pool scaler and the landing page (history kept with `git subtree`), the extension `eduide-session`, charts (CRDs, control plane, landing page), docs and ADRs. IDE images, `EduIDE-Helm`, e2e and load tests for real images, and other extensions stay outside. The workspace garbage collector is dropped. One release tag `vX.Y.Z` versions everything. | [0002](0002-go-single-module-four-binaries.md), [0018](0018-charts-oci.md) |
| U3 | GitHub | Public repo `EduIDE/EduIDE-control-plane`, marked experimental in README, description and topics. Images under `ghcr.io/eduide/eduide-control-plane/*`. | [0002](0002-go-single-module-four-binaries.md), [0018](0018-charts-oci.md) |
| U4 | CI | `golangci-lint`, `go test` with envtest, `govulncheck`, Trivy, `npm audit` and ESLint, Gitleaks, Renovate. API fidelity: OpenAPI lint, `oasdiff`, contract tests, CRD schema diff, `make generate` without diff. Path filters per part. | [0010](0010-rest-api-spec-first.md), [0011](0011-crd-versioning-cel.md), [0015](0015-test-strategy.md) |
| U5 | Images | Multi-stage, production image `gcr.io/distroless/static-debian12:nonroot`. The landing page uses a small static Go server, also distroless. | [0002](0002-go-single-module-four-binaries.md) |
| U6 | University independent | No university defaults in the repo. Hosts, realm and pool label only in values outside (EduIDE-Helm or test values). | [0003](0003-own-crd-group.md), [0014](0014-operator-service-per-deployment.md), [0018](0018-charts-oci.md) |
| U7 | Node pools | Placement profile per deployment (node selector, tolerations, affinity), overridable per template. Capacity pressure per node pool, only idle pods of the same pool are evicted. Prepull only on nodes of the matching pool. The label key is configurable. | [0008](0008-idepool-scale-bare-pods.md), [0014](0014-operator-service-per-deployment.md) |
| U8 | IDE images | No compatibility mode in the agent. An experimental pull request in the image repository replaces the data bridge and monitor with `eduide-session` and moves the webview and mini browser host to G3. Test images use its PR tags. | [0006](0006-agent-sidecar.md) |
| U9 | Test environment | A dedicated test namespace on the shared test cluster with its own gateway (same GatewayClass, `mergeGateways`), certificates through the cluster issuer and Helm releases there. New CRDs of the group are approved cluster-wide. Existing namespaces, the shared gateway and the production context stay untouched. | [0015](0015-test-strategy.md), [0017](0017-migration-parallel-run.md) |
| U10 | Keycloak for the test deployment | Same client as the existing test deployments (confidential). The secret is copied by pipe without printing. Redirects for the instance host are registered. The gateway callback is on the instance host and `cookieDomain` includes the webview host. | [0005](0005-session-auth-at-gateway.md), [0017](0017-migration-parallel-run.md) |
| U11 | Start estimate per template | The service keeps observed start durations per template and persistence mode and returns `startEstimate` in `GET /templates` and in the new stream `GET /templates/events`. | [0020](0020-landing-page-data-in-the-api.md) |
| U12 | Template metadata from the image | The operator reads the OCI annotation `io.eduide.template` once per digest into `IDETemplate.status.image`; `GET /templates` returns `variants`, `includes`, `imageVersion`. | [0020](0020-landing-page-data-in-the-api.md) |
| U13 | Lifecycle times in the API | `Session.stopsAt`, `Session.stopReason`, `Workspace.deletesAt` and both on overview items. | [0020](0020-landing-page-data-in-the-api.md) |
| U14 | Delete from the overview | `DELETE /workspaces/{name}` stops a running session and deletes the workspace in one call. | [0020](0020-landing-page-data-in-the-api.md) |
| U16 | Read-only admin API | `GET /api/v1/admin/*` (tag `admin`), access by a Keycloak realm or client role in the token (`oidc.admin`), 404 without config, 403 without the role. Users only as `ownerHash`, launch data only as key names. Optional Prometheus. New metric `eduide_session_failures_total`, scaler events `ScaledUp`, `ScaledDown`, `Held`. | [0021](0021-admin-api-and-public-status.md) |
| U17 | Public status | `GET /api/v1/status` without token: overall, sign-in, starting and workspaces health and per template start estimate and warm flag. Cached 15 s, rate limited per IP, strict field allowlist. | [0021](0021-admin-api-and-public-status.md) |
| U18 | In-IDE feedback | `POST /api/v1/feedback` authenticated by the instance token (called by the agent, not by browsers), rate limit 5 per hour per session owner, redaction, no user identity forwarded to the central receiver. Operator switch `config.feedback.enabled`, default off (404). | [0023](0023-in-ide-feedback-path.md) |
